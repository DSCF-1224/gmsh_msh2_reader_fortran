# gmsh_msh2_reader_fortran

Fortran module for reading [Gmsh][GmshReferenceManualTop] [MSH file format version 2][GmshReferenceManualMsh2]

> [!IMPORTANT]
> This library does **not** support following [Gmsh][GmshReferenceManualTop] MSH format versions.
> - [MSH file format version 1][GmshReferenceManualMsh1]
> - [MSH file format version 4][GmshReferenceManualMsh4]

> [!TIP]
> [gmsh_msh1_reader_fortran](https://github.com/DSCF-1224/gmsh_msh1_reader_fortran) supports reading [Gmsh][GmshReferenceManualTop] [MSH file format version 1][GmshReferenceManualMsh1].
